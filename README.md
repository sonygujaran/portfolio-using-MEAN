# Portfolio Using MEAN Stack (MEAN Stack)
A full-stack web application built with the **MEAN stack** (MongoDB, Express.js, Angular, and Node.js) to manage and display professional portfolio data, including certifications, education, work experience, internships, projects, and technical skills.

## Tech Stack
- **Frontend:** Angular, TypeScript, HTML, CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB

## Features 
Manage records across 6 core portfolio sections:
  - Certifications
  - Education
  - Work Experience
  - Internships
  - Projects
  - Skills
- **RESTful API:** Modular Express routes and Mongoose models for clean data handling.
- **Responsive UI:** Built with Angular for a dynamic single-page application experience.
